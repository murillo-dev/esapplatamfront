# Prueba esAppLatam

Esta es una prueba phecha en Angular en su version 20.2

# Clonar el proyecto de github

```bash
git clone git@github.com:murillo-dev/esapplatamfront.git -b develop
cd essapplatamfront
npm i
```

clonamos de la rama develop

# Correr el proyecto

```bash
ng serve
```

# Resumen

Se aplico angular-material, se uso un store para guardaar los datos, todos los datos son usados por un mock generado automaticamente,se uso signals para el manejo de datos y servicios, se crearon interfaces para no tener problemas para el uso de datos asi usaos mejor typescript para los tipados, las carpetas estan hechas para ser escalables, se pueden adicionar sin ningun problema mas componentes para adicionar funcionalidades, tambien separamos rutas, se puede adicionar facilmente algun metodo de autenticacion.
